The Challenge

Bridging Studio Operations

Eliminating browser tab clutter and manual spreadsheets across multi-title game production.

The Problem

Independent game studios face fragmented operations. Production schedules live in Trello, financial & sales telemetry lives behind Steamworks portals, and community patch alerts are manually published to Discord. Release managers waste hours copy-pasting milestone data with no unified source of truth.

The Solution

The Mudhen Release Manager bridges these silos into a high-performance web dashboard. It automates milestone countdown tracking, synchronizes real Steam partner data, provides one-click rich Discord webhook announcements with persistent audit history, and delivers live multi-user collaboration over WebSockets.

Engineered Capabilities

Core System Features

Comprehensive tools built to streamline independent game delivery pipelines.

Live Multi-User Kanban

Dynamic, customizable production stages with drag-and-drop task organization. Instant state propagation across all connected studio members powered by ASP.NET Core SignalR.

Discord Webhook Broadcasts

One-click milestone patch notes and playtest announcements dispatched directly to community and developer channels with rich embed formatting and persistent audit trails.

Steamworks Analytics

Integrated telemetry pulling live daily active users (DAU), total unit sales, refund rate analytics, and revenue metrics directly from official Steamworks partner endpoints.

Trello Board Synchronization

Seamlessly import and adopt Trello board lists into project Kanban stages with authenticated attachment caching, proxying, and checklist item resolution.

Role-Based Access Control

Granular permission gating for Administrators, Editors, and Viewers. Hardened with PBKDF2 password hashing, secure JWT cookies, and IP-level brute-force rate limiting.

Milestone Countdowns

Target release countdown clocks with automatic overdue detection, build version stamping (SemVer), and project health indicators to keep teams aligned on deliverable dates.
